# teco-account-intelligence

目标客户背景调查与关键人沟通分析。将公司公开信息转化为客户开发优先级、交易风险提示与具体切入方案。

Copyright (c) 2026 tecoatwork

## 适合什么任务

- 输入公司名称或官网URL，核实法律主体、业务、渠道和公开风险。
- 结合我方产品判断客户下游需求和合作价值。
- 基于关键人的公开职业行为制定沟通策略。
- 设备、特种车辆、铸件等重工业客户的项目与履约核查。

该Skill是AI助手工作指令，不是自带征信数据库或自动调查程序。运行需要支持SKILL.md的助手；当期事实核验需要搜索及网页阅读工具。不依赖私人路径或其他特定Skill。

## 使用

```text
$teco-account-intelligence
目标：https://example.com （替换成真实目标官网）
我方产品：提供实际产品简介或附件
风险偏好：中性
请连续完成三个阶段。
```

```text
$teco-account-intelligence
目标：公司全称与国家
行业：重工业
风险偏好：保守
仅阶段1，等我说下一步。
```

默认中性风险偏好、中文报告、连续三个阶段。输入缺失时先检索，不能确认的项目列获取路径；同名主体无法消歧时可提出一个必要识别问题。

## 输出

1. 主体和业务核查、开发优先级、财务履约与合规风险、评分依据和来源。
2. 供应链角色、关键人的职业沟通偏好与待验证痛点。
3. 切入逻辑、三条开发信首句和一个低压力CTA；只起草，不发送。

来源等级与结论可信度分开。100分框架允许未知项，并显示已评权重与覆盖率；不虚构完整信用分、付款记录或授信额度。DISC仅作可选、低置信度沟通假设，不能当人格测评或参与信用判断。

## 安装

将本仓库整体放入助手的技能目录，文件夹命名为 `teco-account-intelligence`。Codex常见个人目录为 `~/.codex/skills/`，自定义配置以实际环境为准。

也可将本仓库链接发给Codex，请它使用skill-installer安装根目录的Skill。安装后打开新会话；未发现时检查路径或重启客户端。

## 结构

- `SKILL.md`：触发条件、三个阶段及交付规则。
- `references/assessment.md`：证据、评分、付款与关键人分析规则。
- `agents/openai.yaml`：Codex显示与调用元数据。
- `COPYRIGHT`、`LICENSE`：版权与MIT许可。

## 限制与验证状态

公开信息可能缺失或过时；未发现负面不代表没有风险。输出不替代正式信用审批、法律审查或人格测评。不会自动联系客户、购买资料或公开研究对象的信息。

初版完成结构、元数据和规则一致性检查，尚未进行真实公司的端到端调研验证。不要把示例或建议当成已经完成的调查。
